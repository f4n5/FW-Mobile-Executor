How it works

External inject. Not a modded Roblox APK. Four steps on phone.

01
Install host APK (Android) or sideload IPA (iOS). Unknown sources / AltStore · Sideloadly · TrollStore.
02
Open Roblox Stock client. Join any game. Leave it in the foreground.
03
Attach → Inject Host finds process, loads runtime (.so / dylib), arms ScriptContext.
04
Execute Paste or hub → Execute. Full UNC bootstrap prepended every run.

FAQ

What is Shiv Mobile?
External-inject Roblox executor for Android and iOS. Host app attaches to the stock Roblox process, loads a runtime, arms ScriptContext, and runs Luau with a full UNC + sUNC surface. identifyexecutor returns "Shiv Mobile".
Is this a modded Roblox APK like Delta?
No. Delta-class tools often ship a modified Roblox client. Shiv Mobile is external: you keep the official client, install a separate host, then Attach → Inject. Lower update pain; stock signature stays intact.
Do I need root or jailbreak?
Android: UI works without root. Reliable inject is stronger with root or a debuggable target. iOS: UI + license work on plain sideload; full process inject needs TrollStore entitlements or a jailbreak / rootless path.
What is UNC / sUNC coverage?
Full catalog: environment, identity (level 8), closures, metatable, filesystem, HTTP, encoding, crypt, Drawing, instances, scripts, cache, input, debug, signals, websocket, actors, misc. Bootstrap is prepended on every Execute so hubs resolve names even before native bindings replace stubs.
How does pay → key → download work?
Click Day / Week / Month — you are sent to the payment URL. After you pay, email proof of payment and the Gmail you want the key on to staff. Staff creates a one-time receipt and sends it to that Gmail. Redeem the receipt on the keys page (once only). You get a SHIV-… license key. Paste that key under Download to unlock APK / IPA. Desktop FW uses Discord tickets instead of email; mobile is email-only.
Is the receipt one-time?
Yes. Each receipt works once. Reusing it shows “already used.” The license key issued from it is what unlocks downloads and the app.
Can one key cover Android and iOS?
Yes. A single active key unlocks both platform builds. HWID locks on first redeem in the app. Month includes one HWID reset via staff.
Will I get banned?
Any third-party executor carries risk. Hyperion exists on mobile too. External inject reduces some package-level signals vs modded clients, but runtime behavior still matters. Use alts. No executor is permanently safe.
Refunds?
No refunds after key activation. If a key never activated, contact support within 24h of purchase for case-by-case review. Day plan is the low-risk trial.
Where is support?
Discord support for Week / Month. Priority queue for Month. Include key prefix (not full key), platform, Roblox version, and whether Attach, Inject, or Execute failed.
